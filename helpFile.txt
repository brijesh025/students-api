   ->clean ev is a tool that helps you manage your environment variables in a clean and organized way. It allows you to create a .env file where you can store your environment 
   variables, and it will automatically load them into your application when you run it. This is especially useful for managing sensitive information like database credentials, 
   API keys, etc.

4. e := godotenv.Load(); 
   if e != nil {
       log.Fatal("Error loading .env file")
   }
   -> this code is used to load the environment variables from the .env file. It will look for the .env file in the root directory of your project and load the variables 
   defined in it into your application. If there is an error loading the file, it will log a fatal error message.
   -> then we can use the os package to access the environment variables in our code, for example:
   -> configPath := os.Getenv("CONFIG_PATH")

1. channel vs waitgroup use:
   -> channels are used for communication between goroutines, they allow you to send and receive values between goroutines. They are useful for synchronizing the execution of 
   goroutines and for sharing data between them.
   -> waitgroups are used to wait for a collection of goroutines to finish executing. They allow you to specify a number of goroutines that you want to wait for, and then 
   block until all of those goroutines have finished executing. They are useful for ensuring that all goroutines have completed their work before the main goroutine exits.
